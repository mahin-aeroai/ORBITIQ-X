## Failure Cases

**`doi` attribute warning** — `ChunkMetadata` missing `doi` field used by hallucination guard. Non-fatal (falls back to graph-only context assembly) but reduces citation quality. Fixed in `e598d3f`.

**`report_number`, `page_start`, `page_end`, `authors`, `year`, `title`, `doc_id`** — All missing from initial schema definition. Fixed across multiple commits. All schema fields now complete.

**Pipeline instantiation missing** — `pipeline = _OpenAIPipeline(...)` was lost during line-based editing of `rag.py`. Fixed in `341c137`. This caused all API queries to return graph-only responses for several deploys.

## Operational Recommendations

1. **Increase corpus size** — 17 chunks is a minimal seed. Target 200+ chunks from authoritative PDFs once URL access is resolved (Railway IP unblocking or S3 pre-download approach).

2. **Upgrade embedding model** — `all-MiniLM-L6-v2` (384-dim) provides good semantic similarity but larger models (BGE-M3, E5-large) would improve retrieval precision. Requires GPU or model serving.

3. **Reduce latency** — 19s average is dominated by Claude synthesis (~10-15s) plus ST encoding (~1s) plus Qdrant (~200ms). Streaming responses would improve perceived latency.

4. **Add `doi` and `report_number` to ingestion pipeline** — corpus_service already passes these fields; schemas now accept them.

5. **Redis activation** — Enables response caching, reducing repeat query latency.
