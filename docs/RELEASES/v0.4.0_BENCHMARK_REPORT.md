## Latency Analysis

Average latency increased from 19s to 28s with 10× corpus expansion. Latency is dominated by Claude Sonnet synthesis (~20-35s). Vector retrieval (sentence-transformers + Qdrant) is fast:

| Component | Estimated Latency |
|---|---|
| ST encoding (query) | ~500ms |
| Qdrant vector search | ~200ms |
| Neo4j graph context | ~1,000ms |
| Claude synthesis | ~20,000-40,000ms |
| Total | 22,000-42,000ms |

Claude synthesis dominates. Streaming responses would dramatically improve perceived latency.
